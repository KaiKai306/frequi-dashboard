# 可复现的 BTC/ETH 回测

首轮采用 Freqtrade 2026.10，与日本模拟服务相同的镜像摘要。实验参数在结果产生前冻结于 [PROTOCOL.md](PROTOCOL.md)，本轮没有 Hyperopt、股票、账户凭据或自动切换模拟策略。

- `prepare_data.py`：逐包验证118份官方月度ZIP及CHECKSUM，生成1h与完整4h Feather。输入为此前保存的 `history_<symbol>_<yyyy>_<mm>.raw` 与 `_sha256.raw`。
- `strategies/`：生产双均线基线的副本及两套固定参数候选。
- `run_matrix.py`：四区间×两成本，每组同时运行三策略，共24项。结果和日志写到指定工作目录，存在结果时跳过已完成组。
- `offline_freqtrade.py`：只将交易所市场发现替换为已保存的公共市场快照。策略、撮合、精度、保护、钱包、统计均使用正式引擎。运行环境必须断网，无凭据挂载。
- `check_causality.py`：三策略×两币×五截断点，共30次指标与信号前缀一致性检查。
- 官方 `lookahead-analysis`：每策略抽查10个信号，CSV报告保存于实验工作区。
- `export_report.py`：读取正式ZIP、钱包快照和检查结果，独立核对每笔费用/利润及最终余额，输出前端报告。
- `../../public/backtests/report.json`：完整回测报告，只有公共行情与1000USDT假设账户，无真实账户数据。前端按登录账号从同源受保护路径读取。

本次源归档和复现工作目录为 `/srv/ccpocket/workspace/tmp/2026-10-31/quant-backtests/`，公共市场快照为其 `markets.json`，无API凭据；配置模板为 `config.example.json`。原归档保留，不随Git重复提交。原始Freqtrade ZIP、引擎日志、逐笔核对和偏差检查证据均留在工作区。

研究机运行 `python3 research/backtests/run_matrix.py --work <工作目录>`。脚本通过 sudo 启动新建的一次性容器，不访问已有容器：固定镜像、网络关闭、无端口、只读根目录、1.5 CPU / 1800MiB限制、只挂载研究源码和工作目录。镜像原Python用户1000及工作区组997用于访问只读依赖；工作目录需给该组读写，脚本目录给该组只读。准备数据和导出同样使用 `docker_base()` 的隔离参数，执行对应Python脚本。

报告口径：账户净值含持仓价值，期末与引擎余额对齐；最大回撤用完整4h开盘快照，曲线按日抽样。基准是各100USDT预算买入BTC/ETH，其余资金现金。费用输入包含假设手续费及以费用近似的滑点，不代表真实账户费率。历史区间此前已被查看，本轮不是未见数据的样本外测试。当前市场精度用于全部历史区间，缺失数据与期末撮合边界见报告。

新回测先在研究机验证，发布报告和静态前端，保留旧资源，最后原子替换首页。`/preview/backtests/*` 在现有公开Caddy通过原面板认证，并拒绝写方法；现有机器人网关权限不扩展。初版支持已完成报告的筛选、比较、详情与下载；页面不提交任意回测命令或修改模拟策略。

本轮各区间结果及解释见 [RESULTS.md](RESULTS.md)。
